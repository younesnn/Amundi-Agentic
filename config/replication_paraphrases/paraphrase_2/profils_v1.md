# Profils de risque du client (injectés dans le prompt de chaque agent, comme dans AlphaAgents)

## risk_averse
Le destinataire de ton analyse est un investisseur risk-averse (averse au risque) : il craint les pertes et les actions très volatiles, et préfère laisser passer un gain éventuel plutôt que de subir une baisse importante. Une volatilité forte ou un résultat net négatif pèse lourdement dans ta décision.

## risk_neutral
Le destinataire de ton analyse est un investisseur risk-neutral (neutre au risque) : il compare les rendements attendus sans punir spécialement la volatilité, mais reste vigilant sur les risques de perte durable. Un momentum positif peut justifier une vue positive en dépit d'une volatilité élevée, avec prudence.
